# FinSathi — Free Personal Finance Advisor
**A free finance-planning app I designed, built and launched.**
🔗 **Live app:** https://arvcreats.github.io/finsathi/ &nbsp;|&nbsp; 💻 **Source code:** https://github.com/Arvcreats/finsathi

FinSathi helps anyone plan money in minutes — no sign-up, no cost:
- 📊 50/30/20 budget plan with emergency-fund and goal planning
- 🎯 Up to 5 savings goals with a live expense tracker
- 🧮 SIP and EMI calculators with charts and what-if sliders
- 🌐 English, Hindi and Hinglish
- 📱 Installable web app (PWA) — also available as an Android APK

Built with HTML, CSS and JavaScript. Calculations run in code (never AI guesses); an optional bring-your-own-key AI only explains the plan.
